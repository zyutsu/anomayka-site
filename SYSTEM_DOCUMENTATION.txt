1. ГЛАВНАЯ ЦЕЛЬ И ИДЕЯ ПРОЕКТА
--------------------------------------------------------------------------------
Создана автоматизированная платформа для продажи готовых сайтов и онлайн-записи
автосервисам Московской области и ЦФО, у которых нет своего сайта.

Вместо длинных холодных звонков и шаблонных коммерческих предложений применяется
стратегия «показать готовый продукт на деле»:
1. Автосервис находит себя в базе.
2. Для него уже автоматически собран персональный рабочий сайт:
   - С его реальным названием и точным адресом;
   - С его реальным логотипом/фотографией фасада из Яндекс Карт;
   - С онлайн-записью клиентов по слотам времени;
   - С интерактивной точкой и маршрутом на Яндекс Картах;
   - С подобранной цветовой гаммой и каталогом услуг (ТО, Тюнинг, Детейлинг, Шиномонтаж).
3. В таблице нажимается одна кнопка — сразу открывается диалог в WhatsApp или Telegram
   с этим автосервисом, где уже впечатан весь продающий текст со ссылкой.
4. Вы просто нажимаете клавишу ENTER, и сообщение уходит!

2. АРХИТЕКТУРА САЙТА И ТЕХНОЛОГИИ
================================================================================
- Стек: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons.
- Хостинг и продакшен: Vercel (Production URL: https://vibe-rho-bay.vercel.app).
- База данных: Гибридное хранилище Vercel Blob Storage + локальная база JSON
  с in-memory кэшированием (для сверхбыстрой отдачи страниц без задержек сети).
- Репозиторий: GitHub (zyutsu/anomayka-site, ветка master).

Основные разделы сайта:
- Главная страница: Витрина автосервиса, онлайн-календарь бронирования, выбор услуг,
  карточки преимуществ, отзывы, FAQ, карта проезда.
- /booking: Пошаговый мастер онлайн-записи на свободные временные слоты.
- /services: Каталог услуг с фильтрацией по категориям и фикс-прайсом.
- /contacts: Контактные данные, интерактивный маршрут на Яндекс Картах.
- /faq: Ответы на частые вопросы клиентов.
- /admin: Панель администратора с управлением заявками, услугами, слотами и генератором демок.

4. СИСТЕМА КОРОТКИХ ССЫЛОК И УМНЫХ ШЛЮЗОВ
================================================================================
Для каждого автосервиса создана система из нескольких взаимосвязанных URL:

1. /d/[slug] — Короткая ссылка на персональный сайт:
   Пример: https://vibe-rho-bay.vercel.app/d/avtoservis-podolsk-1
   - Моментальный 307 HTTP-редирект (0-50 мс) на главную страницу с параметрами:
     name, phone, city, address, color, slogan, cats, logo, map.
   - Если ссылка открывается впервые или база недоступна — срабатывает умный fallback:
     название сервиса восстанавливается прямо из слага, и сайт открывается корректно.

2. /wa/[slug] — Веб-шлюз для WhatsApp:
   Пример: https://vibe-rho-bay.vercel.app/wa/avtoservis-podolsk-1
   - Обходит внутреннее ограничение Microsoft Excel на длину ссылок (2048 символов).
   - В Excel вставляется ссылка длиной всего 55 символов.
   - При клике шлюз мгновенно перенаправляет браузер на web.whatsapp.com/send
     с ПОЛНЫМ текстом сообщения (все 5 абзацев + ссылка + примечание про VPN).
   - Чат открывается прямо с нужным номером, а курсор уже стоит в конце напечатанного сообщения.

3. /tg/[slug] — Веб-шлюз для Telegram:
   Пример: https://vibe-rho-bay.vercel.app/tg/avtoservis-podolsk-1
   - Обходит блокировку Excel на ссылки вида "tg://".
   - Моментально копирует полный текст сообщения в буфер обмена.
   - Запускает Telegram Desktop / мобильный Telegram прямо в диалог с этим автосервисом
     по его номеру телефона (tg://resolve?phone=...&text=...).
   - Никаких всплывающих окон «Переслать/Поделиться» — открывается только прямой чат.

4. /send/[slug] — Хаб быстрой отправки (1-клик):
   Пример: https://vibe-rho-bay.vercel.app/send/avtoservis-podolsk-1
   - Веб-страница с карточкой автосервиса, логотипом, телефоном и кнопками в 1 клик.
   - Автоматически помещает текст в буфер обмена при входе.
   - Позволяет в 1 клик открыть WhatsApp, Telegram, скопировать текст или открыть демку.

5. ПАРСИНГ ЛОГОТИПОВ ИЗ ЯНДЕКС КАРТ (198 из 200)
================================================================================
- Был запущен многопоточный Python-парсер (16 потоков), который обратился к каждой
  карточке Яндекс Карт из исходной таблицы (https://yandex.ru/maps/org/{id}/).
- Из метатегов <meta property="og:image" content="..."> были спарсены прямые ссылки
  на оригинальные фотографии фасадов, боксов и логотипов сервисов на серверах Яндекса
  (avatars.mds.yandex.net/get-altay/...).
- Из 200 сервисов реальные фотографии найдены для 198 автосервисов!
- Фотографии сохранены в кэш data/yandex_logos_cache.json и вшиты в ссылки сайтов.
- Теперь при открытии сайта сервиса в шапке и превью отображается его реальное фото!
